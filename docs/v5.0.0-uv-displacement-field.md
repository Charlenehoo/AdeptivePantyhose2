# v5.0.0 远期展望：基于 UV 流形与单射位移场的自适应网格形变

**状态**：理论研究与远期规划，尚未进入工程落地阶段。
**关联**：在 [v4.0.0 Walk Mesh 重构](v4.0.0-walk-mesh-refactor.md) 落地并稳定后，再行探索。

---

## 1. 核心动机：摆脱 Morph Target 的束缚

当前架构（包括 v4.0.0）依然依赖 BodySlide 的 Morph Target 体系。如果艺术家在制作高跟鞋时没有烘焙对应的 Morph（如 `NoHeel`），或者制作丝袜时没有包含相关滑条，插件就无能为力。

本方案试图利用微分几何与图形学算法，实现完全独立于 Morph 体系的“物理级”衣物自适应。

## 2. 核心不变量（The Invariants）

该方案建立在两个游戏界的底层物理事实上：

1. **材质兼容不变量**：艺术家在制作任何非标准脚模（如踮脚尖的高跟脚）时，为了复用游戏通用的皮肤/丝袜材质，必须兼容原始平脚模型的 UV 展开。因此，所有脚模在 UV 空间（及其商空间）天然具有映射关系。
2. **拓扑存在不变量**：任何鞋型要么内嵌了脚模（如高跟靴），要么未内嵌（如高跟凉鞋）。只要脚本身需要露出，就必然存在脚模。

## 3. 算法管线设计

### 3.1 无脚模场景（如凉鞋）

直接对长筒袜模型应用 Mask 裁剪，不渲染其“脚”部分的网格。这从根本上消除了强行拉伸导致的穿模。

### 3.2 有脚模场景（如高跟靴）

1. **UV 拉回**：将原始平脚模型与高跟脚模的 3D 流形拉回 UV 坐标的商空间。处理 UV 岛的多对一映射，保证纤维映射的正确性。
2. **计算位移场**：在 UV 空间计算从平脚到高跟的单射位移场（Injective Displacement Field）。
3. **邻域形变传递**：由于丝袜必然在脚模的测地线拓扑邻域内，将该位移场直接施加于丝袜网格的顶点上，实现像素级的完美贴合。

## 4. 性能与工程分层

- **离线烘焙（Blender Python）**：对于复杂的非线性形变（如 ARAP - As-Rigid-As-Possible 算法），通过离线脚本预计算位移场，导出为位移贴图或顶点缓存文件。
- **运行时计算（C++）**：利用拉普拉斯形变（Laplacian Deformation）求解稀疏线性方程组，在毫秒级内对局部网格（脚部几千个顶点）进行实时形变。
